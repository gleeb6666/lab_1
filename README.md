# Задача 8. Роздача кісток доміно

## Збірка
```
g++ -std=c++23 -Wall -Wextra -O2 main.cpp dominodealer.cpp game.cpp statistics.cpp -o domino
```

## Вхідні дані (з клавіатури)
1. `n` — найбільше число на кістці, ціле від 0 до 20.
2. Кількість роздач — ціле від 1 до 1 000 000.

Кожне число вводиться окремим рядком. Якщо введено не ціле число, порожній рядок
або число поза діапазоном — програма повідомляє про помилку і просить ввести ще раз.

## Правила роздачі
- Роздача починається з повного комплекту: (n+1)(n+2)/2 кісток.
- Перша кістка кладеться на стіл, далі кожна наступна прикладається до одного з вільних кінців.
- Якщо кістку можна прикласти обома числами, вона прикладається меншим.
- Роздача зупиняється на першій кістці, яку прикласти не можна (або коли кістки закінчились).
- Розмір роздачі — кількість розданих кісток, включно з тією, на якій роздача зупинилася.

## Файли
- `domino.h` — кістка доміно, порівняння через `operator<=>`.
- `dominodealer.h/.cpp` — клас функціональних об'єктів, `operator()` видає випадкову кістку із залишку.
- `game.h/.cpp` — ланцюжок кісток і проведення роздач.
- `statistics.h/.cpp` — підрахунок %, найчастішого, середнього та медіанного розміру.
- `main.cpp` — введення, виведення статистики та експеримент для n = 0..введене n.
